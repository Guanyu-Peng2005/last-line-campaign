# 最后防线 · 尸潮战役

手机竖屏网页小游戏，12 关自动战斗与自由部署。

## 游玩

打开 GitHub Pages 地址，在选关后招募并逐个部署部队，点击出战。支持暂停、2×速度与本地存档。

医疗兵和维修车会救援、闪避并组成支援队形。战斗中的金币先待结算；正常胜负结算才到账，主动撤退或刷新中断不发放本局收益。

可在手机浏览器中添加到主屏幕。存档保存在当前浏览器和设备中，电脑本地试玩进度不会自动同步到手机；清除浏览器数据会删除该浏览器的存档。

## 发布包

此仓库仅保存完整游戏的压缩发布包，不包含视频创作台、导出视频、测试数据、开发源码或独立音效文件。素材来源及使用条款见 [CREDITS.md](CREDITS.md)。
